Nexus POS — Offline Desktop Point of Sale for Bangladeshi Shops
A fully offline desktop point-of-sale for small shops in Bangladesh. Installs like a normal Windows or Ubuntu program, opens one native window and works with no internet at all. Prints Bangla and English receipts on any 80mm thermal printer, produces the NBR Mushak 6.3 VAT challan, and keeps every sale in one SQLite file on the shop's own computer. A closed-source commercial product with a licensing system — built to be sold, not just demoed.
  • Bangla on printers with no Bangla font: receipts render as 1-bit bitmaps sent via ESC/POS raster. Wrote a custom text shaper on HarfBuzz + FreeType (avoiding LGPL libraqm in a closed-source product), validated pixel-for-pixel against Pillow's output, with shaping self-checks at build, startup and on the printed test page.
  • Exact money arithmetic: integer poisha and milli-units only, no floats. Bill discounts allocated across lines by largest-remainder so parts always sum; VAT computed the way NBR expects. The engine exists twice — Python as the authority, TypeScript for live cart updates — and the server recomputes on save.
  • Immutable, auditable invoices: no edit endpoint; corrections are voids with reason and user. VAT rate, pricing mode and shop identity are snapshotted onto every invoice so a reprint years later shows what was actually charged.
  • Hand-written ESC/POS driver: raster bands, feed, cut, cash-drawer pulse and CODE128 barcodes, verified on Epson and common Chinese clones; targets Windows spooler RAW, USB, network port 9100, file dump and a discard mode. A print failure never fails a sale.
  • Offline licensing: Ed25519-signed licences bound to hashed hardware signals with a tolerance rule, 14-day grace after expiry, check in two places, and an adversarial test suite (forged keys, edited keys, wrong machine, copied files).
  • Built for a shop PC that loses power: SQLite WAL with synchronous FULL, cart persisted to localStorage, VACUUM INTO backups during trading, invoice numbering safe under races, and additive self-healing schema upgrades so an update never depends on someone running a migration.
  • Real desktop packaging: one-folder PyInstaller build, Inno Setup installer that silently installs WebView2, a portable build, a Debian package, and a GitHub Actions Windows runner; a built-in self-test checks fonts, shaping, UI bundle, data folder and 576-dot receipt rendering.
